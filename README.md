# NLP, Time Series, and Neural Networks Lab

## Project Overview
This project explores Natural Language Processing (NLP), time series analysis, and neural networks using an Amazon reviews dataset. It demonstrates how data science techniques can be used to analyze customer reviews, identify trends over time, and predict review ratings from text.

## Objectives
- Perform text analysis and preprocessing on Amazon customer reviews.
- Explore review activity and rating trends over time.
- Build and evaluate a neural network model to predict ratings from review text.
- Assess model performance using appropriate evaluation metrics.

## Dataset
The project uses `amazon_reviews_lab.csv`, which contains Amazon review data used for the NLP, time series, and neural network tasks.

## Project Structure
- `C09_M08.ipynb` — Jupyter Notebook containing the analysis and model development.
- `amazon_reviews_lab.csv` — Dataset used in the project.
- `README.md` — Project documentation.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Natural Language Processing techniques
- Neural networks
- Jupyter Notebook

## How to Run
1. Clone or download this repository.
2. Ensure Python and the required libraries are installed.
3. Open `C09_M08.ipynb` in Jupyter Notebook or VS Code.
4. Ensure `amazon_reviews_lab.csv` is in the same project directory.
5. Run the notebook cells in order.

## Model Evaluation
The neural network models are evaluated using classification metrics, including accuracy and macro F1-score. These metrics help assess both overall prediction performance and performance across rating classes.

## Conclusion
This project applies NLP, time series analysis, and neural networks to Amazon review data. It also explores the challenges of predicting ratings when the rating classes are imbalanced.
